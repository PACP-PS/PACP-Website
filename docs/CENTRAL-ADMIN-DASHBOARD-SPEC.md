# PACP — لوحة الإدارة المركزية: نطاق الواجهة والصلاحيات

## الأقسام
1. نظرة عامة: مؤشرات حية فقط من قاعدة البيانات، وتنبيهات المهام دون بيانات نموذجية.
2. العضوية: طلبات الانتساب، مراجعة المستندات، القرارات، توليد رقم العضوية، البطاقات والتجديد.
3. الدورات والفعاليات: إنشاء المحتوى ونشره، التسجيل، قائمة الانتظار، الحضور، الإتمام.
4. النقاط والشهادات: التحقق من الاعتماد، منح النقاط، إصدار الشهادات والتحقق منها وإلغاؤها.
5. المالية: رسوم العضوية والنشاط، مراجع الدفعات، المطابقة، الاسترداد والتقارير. لا تخزن بيانات البطاقة البنكية.
6. المحتوى: الصفحات والأخبار والإعلانات العربية والإنجليزية وسجل المراجعة.
7. التقارير: حسب الدور، مع تقليل البيانات الشخصية والتصدير الآمن.
8. المستخدمون والصلاحيات: حسابات الموظفين والأدوار والتفويضات وسجل التدقيق.

## قواعد التصميم
- واجهة عربية RTL افتراضيًا مع دعم إنجليزي LTR.
- تصميم متجاوب للحاسوب والهاتف، وتباين واضح وتركيز على المهام.
- لا تظهر أعداد أو سجلات افتراضية على أنها بيانات حقيقية؛ تعرض الحالة الفارغة أو مؤشرات غير متاحة.
- لا تُنفذ أزرار توحي بتغيير فعلي في النسخة التصميمية.
- تظل ألوان الجمعية أخضر/أبيض مع الأحمر كلون مساعد، والشعار الرسمي هو المصدر المعتمد.

## نموذج الصلاحيات
- مدير النظام: إدارة المستخدمين والإعدادات التقنية.
- مسؤول العضوية: طلبات العضوية والملفات وفق التفويض.
- صاحب قرار العضوية: قبول/رفض ضمن صلاحية موثقة.
- مدير التدريب: إدارة الأنشطة والتسجيل.
- مسؤول الحضور: الحضور والإتمام.
- مفوض الاعتماد: توثيق الاعتمادات والنقاط.
- مسؤول المالية: الدفعات والمطابقة والاسترداد.
- محرر المحتوى: الصفحات والإعلانات.
- المدقق: قراءة سجلات التدقيق والتقارير المصرح بها.

## متطلبات التشغيل
- المصادقة متعددة العوامل لحسابات الإدارة إن أمكن.
- سياسات صلاحيات على مستوى الخادم وقاعدة البيانات.
- سجل تدقيق للعمليات الحساسة.
- حماية CSRF/الطلبات المكررة، تحديد المعدل، والتحقق الخادمي.
- نسخ احتياطي واختبار الاستعادة.
- لا تُستخدم بيانات حقيقية في الاختبار الأولي.
- مراجعة النظام الأساسي واللوائح وتفويضات الجمعية قبل ضبط صلاحيات القرار.
- لا يُنشر على الفرع الرئيسي قبل اختبارات الوظائف والأمن والقبول.

## الحالة
الواجهة HTML تفاعلية للمعاينة فقط. ليست لوحة إدارة عاملة ولا تتصل بقاعدة بيانات أو مصادقة.
