# PACP — Content Inventory and Homepage QA

Status: implementation checklist for the design review stage. This file does not imply that the production website has been changed.

## Content required before public launch

| Section | Required source material | Owner / approval |
|---|---|---|
| Association identity | Official Arabic and English name, registration details, approved logo files | Association / Board |
| About | Approved history, vision, mission, objectives | Board |
| Governance | Current Board names and roles; committee names and mandates | Board; publish only after confirmation |
| Bylaws | Latest registered bylaws and approved amendments | Board / legal review |
| Membership | Eligibility, application documents, fee approval, category rights | Board; rights matrix pending deliberation |
| News | Approved announcement, publication date, image rights | Authorized editor |
| Events and courses | Title, description, dates, venue/platform, trainer, fee, capacity, cancellation policy | Training/event coordinator |
| Research/resources | Verified publications, authorship, permissions and source links | Scientific committee/editor |
| Partners | Approved organization name and logo-use permission | Board / partnership lead |
| Contact | Official address, email, telephone and social URLs | Association administration |

## Do not publish placeholder content
- Do not invent Board or committee members.
- Do not publish fictional events, news, speakers, statistics, testimonials or partners.
- If an area has no approved content, show a neutral empty state or hide the section.
- Publish professional directory profiles only with explicit opt-in consent.

## Homepage design review checklist
- [ ] Official logo file replaces the temporary favicon-based logo reference.
- [ ] Hero illustration is visually reviewed and approved.
- [ ] Hero heading and tagline are approved in Arabic and English.
- [ ] Header, navigation, search and language control work.
- [ ] Every visible navigation item and CTA has a valid destination.
- [ ] No text is baked into the hero artwork; text remains selectable HTML.
- [ ] Desktop, tablet and mobile layouts are reviewed.
- [ ] Arabic RTL and English LTR are reviewed separately.
- [ ] Keyboard focus, contrast, alt text and reduced-motion behavior are checked.
- [ ] Images are optimized and lazy-loaded where appropriate.
- [ ] No sample news or event records are visible.
